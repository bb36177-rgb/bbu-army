พื้นที่นี้มองเห็นได้เฉพาะผู้ที่ทราบรหัสผ่านขั้นสูงเท่านั้น

🛡️ ระบบป้องกันเว็บ / ความปลอดภัย

มาตรการที่เปิดใช้งานอยู่: ป้องกัน XSS จากข้อมูลผู้เยี่ยมชม, ล็อกการเข้าสู่ระบบชั่วคราวเมื่อกรอกรหัสผิดซ้ำ, บันทึกประวัติการเข้าใช้งานทุกครั้ง

📋 คำแนะนำ: ตัวอย่าง Firestore Security Rules (ป้องกันจริงต้องตั้งค่าที่ Firebase Console) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /siteData/{doc} {
      allow read: if true;
      allow write: if false; // เขียนได้เฉพาะผ่าน Cloud Functions/แอดมินที่ยืนยันตัวตนจริงเท่านั้น
    }
    match /siteConfig/{doc} {
      allow read, write: if false; // ห้ามเข้าถึงรหัสผ่านจากภายนอกโดยตรง
    }
  }
}

โค้ดหน้าเว็บ (ฝั่ง Client) ไม่สามารถ "ยิงกลับ" ผู้โจมตีหรือหยุด DDoS ระดับเครือข่ายได้ — การป้องกันจริงต้องตั้งค่าที่ Firebase Hosting / Cloudflare และ Firestore Rules ข้างต้นเท่านั้น
